Este plan resuelve ambos: se valida un esqueleto de 15 páginas primero, y una vez aprobado, la aplicación en el doc es mecánica.

- Destaque del **Bloque C5 (cifras CIF)**: decisión editorial que requiere input explícito.

- Una vez validado, aplicar Bloques A, B, C y D en secuencia.
- Todos los cambios como sugerencias (Insert/Delete).
- Tiempo estimado: 4-5 horas de trabajo focalizado.

**Paso 5 — Envío formal (Martín, 28-29 abril):**
- Correo a Eduardo y Carla con copia a Benja y Eleni.
